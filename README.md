MOEX — Экспорт свечей облигаций

Веб-приложение для скачивания исторических свечей облигаций с Московской биржи (MOEX ISS API) и экспорта в Excel. Запускается двойным кликом, открывается в собственном окне-браузере, не требует установки — окружение и зависимости подтягиваются автоматически.



Возможности





Скачивание свечей по ISIN облигации за произвольный период



Интервалы: 1, 5, 10, 15, 20, 30, 60 минут



Для интервалов 5/15/20/30 мин — автоматическая агрегация из 1-минутных свечей



Автоматическая конвертация CSV → XLSX с разнесением по столбцам



В файле только 5 колонок: begin, open, high, low, close



Живая лог-консоль с прогрессом в реальном времени



Кнопка Stop для прерывания процесса в любой момент



Сохранение через системный диалог «Сохранить как…» или открытие напрямую в Excel



Запуск в собственном окне через встроенный браузер (pywebview)



Автосоздание виртуального окружения и установка зависимостей



Кастомная иконка приложения через ярлык Windows

Назначение каждого файла

launcher.pyw — главный файл запуска. По двойному клику:





Проверяет наличие app.py и format_csv.py



Создаёт виртуальное окружение venv, если его нет



Устанавливает недостающие зависимости (flask, requests, pandas, openpyxl, pywebview)



Запускает app.py в фоне (через pythonw.exe, без консоли)



Открывает окно мини-браузера (pywebview) с приложением



При закрытии окна останавливает Flask-сервер

app.py — Flask-веб-приложение:





Скачивает свечи с MOEX ISS API (пагинация по 500 свечей, retry, задержки)



Агрегирует 1-минутные свечи для нестандартных интервалов



Сохраняет CSV в папку output/



Вызывает format_csv() для конвертации в XLSX



Удаляет промежуточный CSV



Отдаёт XLSX через API: «Сохранить как…» (диалог Windows) или «Открыть в Excel»

format_csv.py — конвертер CSV в XLSX:





Читает CSV, создаёт XLSX через openpyxl



Автоподбор ширины колонок



Работает как модуль (вызывается из app.py) и как отдельный скрипт

create_shortcut.py — создание ярлыка с иконкой:





Создаёт файл MOEX Экспорт свечей.lnk в папке проекта



Ярлык указывает на launcher.pyw и использует app_icon.ico



Запуск: python create_shortcut.py (один раз)

app_icon.ico — иконка приложения:





Мультиразмерная (16/32/48/64/128/256 px)



Доступно 6 вариантов стилей (см. раздел «Иконка и ярлык»)

Почему через ярлык, а не напрямую

.pyw-файлы на Windows получают иконку из ассоциации с Python — её нельзя поменять без изменения системных настроек. Ярлык .lnk — стандартный и чистый способ: иконка своя, а указывает он на launcher.pyw.



Как пользоваться

Веб-интерфейс





В поле ISIN введите идентификатор облигации (например, RU000A10AZ60)



В выпадающем списке Интервал выберите период свечей



Укажите Начало периода и Конец периода (даты)



Нажмите «Скачать данные»

Процесс загрузки





Под формой появляется лог-консоль — чёрная панель с сообщениями в реальном времени:





Страница 1: получено 500 свечей, всего 500



Страница 2: получено 500 свечей, всего 1000



Сохранение CSV...



Конвертация CSV в XLSX...



Готово! Файл сохранён



Над панелью — прогресс-бар (0% → 50% после скачивания → 100% после конвертации)



Кнопка Stop прерывает процесс в любой момент. Промежуточный CSV при этом удаляется

Получение файла

После завершения появляются две кнопки:





«Сохранить как…» — открывает системный диалог Windows, вы выбираете папку и имя файла. XLSX копируется в выбранное место



«Открыть в Excel» — файл открывается в Excel (или другой программе по умолчанию для .xlsx)

Эти кнопки работают через API-запросы к Flask, а не через ссылки — поэтому встроенный браузер pywebview корректно их обрабатывает.

Устранение неполадок

Приложение не запускается





Python не найден — установите Python 3.10+ с python.org и отметьте галочку «Add Python to PATH»



Файлы не найдены — убедитесь, что app.py, format_csv.py и launcher.pyw лежат в одной папке



Окно не открывается — возможно, WebView2 не установлен. Скачайте с официального сайта Microsoft

Пустой файл или нет данных





Проверьте правильность ISIN (пример: RU000A10AZ60)



Проверьте, что облигация торговалась в выбранный период



Попробуйте уменьшить период (например, один месяц вместо года)

Файл не сохраняется





«Файл уже открыт в Excel» — закройте Excel и попробуйте снова



Нет прав на запись — выберите папку, в которой есть права на запись (например, Документы)

Окно браузера не открывается, но сервер запущен





Откройте http://127.0.0.1:5000 в обычном браузере (Chrome, Edge)



Это fallback-режим: приложение работает, но без интеграции с окном

Как запустить в режиме отладки

Если что-то пошло не так, запустите app.py напрямую из консоли, чтобы видеть ошибки:

venv\Scripts\activate
python app.py

Затем откройте http://127.0.0.1:5000 в браузере. Ошибки будут видны в консоли.



Запуск из консоли (для разработчиков)

Без мини-браузера

venv\Scripts\activate
python app.py

Откройте http://127.0.0.1:5000 в любом браузере.

Конвертер как отдельный скрипт

venv\Scripts\activate

Создаст file.xlsx рядом с исходным CSV.



Технические детали





Пагинация: MOEX ISS API отдаёт максимум 500 свечей за запрос. Приложение автоматически перебирает страницы.



Retry: 5 попыток с экспоненциальным backoff (1 → 2 → 4 → 8 → 16 сек) при ошибках 429, 500, 502, 503, 504.



Задержки: случайная пауза 1–2 секунды между страницами пагинации для снижения нагрузки на API.



Потокобезопасность: фоновая задача работает в отдельном потоке, состояние защищено threading.Lock.



Остановка: threading.Event() проверяется между страницами и перед конвертацией. Промежуточный CSV удаляется.



Кодировки: CSV пишется в UTF-8. Имена файлов с русскими символами обрабатываются корректно.



Фильтрация колонок: из ответа MOEX оставляются только begin, open, high, low, close. Колонки volume, value, end отсекаются.



Источник данных

Данные предоставляются Московской биржей через ISS API: https://iss.moex.com/iss/ — без авторизации, бесплатно.
